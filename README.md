# 🐌 electron.nvim

### Bringing the authentic Electron experience to Neovim.

**Neovim starts in 20 milliseconds. That's unacceptable.**

Are you tired of your editor opening instantly? Do you miss the excitement of staring at a loading screen? Does your terminal-based editor feel suspiciously lightweight?

Introducing **electron.nvim** — the revolutionary Neovim plugin that makes your editor slower, one plugin at a time.

Because **performance is overrated.**

## ✨ Features

- 🐌 **Blazing slow startup** — Adds one second of delay per plugin.
- 📈 **Linear scalability** — The more plugins you install, the slower it gets.
- 💻 **Authentic Electron experience** — Without actually installing Electron.
- 🧘 **Mindfulness built in** — Take a moment to reflect on your life choices while Neovim starts.
- 🚫 **Zero productivity improvements** — We guarantee it.
- 🪶 **100% Lua** — All the slowness, none of the JavaScript.

## 📦 Installation

Using Neovim's native package manager (`vim.pack`):

```lua
vim.pack.add({
    'https://github.com/davidkaste/electron.nvim',
})

require('electron').setup()
```

**Important:** Load `electron.nvim` before your other plugins.

Otherwise, you might accidentally experience good performance.

## 🧠 Philosophy

The Neovim community has spent years optimizing startup times.

Lazy loading. Async execution. Native code. Efficient memory management.

**We believe all of this effort was a mistake.**

Modern software should be heavy. It should take time to start. It should make you question whether your computer is powerful enough to edit a text file.

With electron.nvim, we're bringing these industry standards to your terminal.

**Finally, Neovim feels like a modern IDE.**
